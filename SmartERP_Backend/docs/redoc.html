Overview

SmartERP is a billing, inventory, and accounting ERP backend.

This API provides endpoints for managing the resources and operations supported by SmartERP.

API Versioning

The current API uses the /api/v1 version prefix.

Using This Documentation

Explore the available endpoints to understand their HTTP methods, parameters, request bodies, and responses.

As the API documentation expands, additional resource groups and detailed request and response examples will be included.

Units

Create a measurement unit

Creates a new measurement unit for a company in SmartERP.

Access requirements

  • Authentication: Required.
  • Company access: The user must have access to the specified company.
  • Required role: owner or manager.

When should I use this endpoint?

Use this endpoint to create a measurement unit that can be used when managing inventory, such as Kilogram, Litre, or Piece.

Before sending the request

  1. Authenticate the user.
  2. Provide the company ID in the URL.
  3. Send the unit details as a JSON request body.
path Parameters
company_id
required
integer
Example: 1

Unique ID of the company in which the unit will be created.

Request Body schema: application/json
required

Details of the measurement unit to create.

name
string

Full name of the measurement unit.

short_name
string

Short abbreviation used to identify the unit.

Responses

Local development server

http://localhost:3000/api/v1/unit/{company_id}
